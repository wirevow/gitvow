# Code of conduct

We are here to build a small, careful tool. Be kind, be specific, assume good intent, and disagree about code rather than people. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, reviews or any project channel. Maintainers may edit, remove or lock content that violates this and may ban repeat offenders. Report concerns to the maintainers listed in `pyproject.toml`; reports are handled privately.
